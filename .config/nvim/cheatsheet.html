Autocomplete (nvim-cmp + LuaSnip)
j / kNavigate completion menu ↓ / ↑
<CR>Confirm selected item
<Tab>Accept Copilot ghost text AI OR LuaSnip expand & jump forward
<S-Tab>LuaSnip jump backward through snippet
<Alt+\>Manually trigger Copilot suggestion
<Esc>Dismiss Copilot suggestion (stays in insert mode)
<C-Space>Force-open cmp menu
<C-e>Close cmp menu / abort
cmp sources (priority order) nvim_lsp · luasnip · buffer · path · cmdline
AI / Copilot
<Tab>Accept full ghost-text suggestion
<Alt+\>Manually request suggestion
<Esc>Dismiss suggestion, stay in insert
:Copilot statusCheck sign-in state / warning
:Copilot setupAuthenticate with GitHub
Tab is shared: Copilot takes priority when ghost text is visible; LuaSnip takes priority inside a snippet; cmp confirm otherwise.
